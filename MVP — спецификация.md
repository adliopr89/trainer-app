# MVP — спецификация Mini App

> Функциональность текущей версии. Дополняется по ходу обсуждения.
> Обновлено: нативность ТГ (цвета, BackButton, светлая тема), прогресс на
> карточках, история упражнений, удаление записей веса, ккал в меню,
> валидация initData, smoke-тест `app/test/smoke.mjs`.

## Бот

- На команду `/start` отвечает сообщением с **двумя кнопками**:
  - **«Оплатить»** — пока заглушка (ответ «скоро появится»). Дальше: Telegram Stars /
    Prodamus / YooKassa + выдача доступа.
  - **«Открыть приложение»** — открывает Mini App (`WEBAPP_URL`).
- Здоровается по имени (`ctx.from.first_name`).
- **База аккаунтов** — `app/data/accounts.json` (в gitignore): при `/start`
  и при входе в Mini App (`POST /api/me`) пишется `tg_id → { user_name,
  first_name, created, seen }`. Полноценная БД клиентов — этап 2.

## Онбординг (первый вход в Mini App)

При первом открытии Mini App просит заполнить:

- **Имя** — подставляется из `initDataUnsafe.user.first_name`, можно править
- **Возраст**
- **Вес, кг**

Ошибки показываются под каждым полем, невалидное поле подсвечивается розовым.
После сохранения показывается основной интерфейс. Вес из онбординга — первая
точка в истории веса.

## Структура приложения (нижние плашки)

Нижняя навигация Mini App — 3 таба:

### 1. Программы

- Список программ. Сейчас две:
  - **«Крепкий орех»** — силовая: базовые движения, мышцы и рельеф (Опытный, 🥜+👑).
  - **«Хуяе как худею»** — жиросжигание: больше повторов, меньше веса, короткий отдых (Новичок, все пакеты).
- Карточка программы: название, **розовой строкой — уровень, пакеты, длительность в неделях**, описание, группа, **прогресс-бар выполнения** (выполнено упражнений из всех).
- **Фильтры сверху:**
  - чипы пакетов (Все / ⭐ Старт / 🥜 Уверенная / 👑 VIP) + чекбокс **«Доступное мне»** (включён по умолчанию) — оставляет программы из купленного пакета;
  - чипы групп тренировок (Все / Формы / Похудение / Набор массы).
- Программа не из пакета пользователя — серая с 🔒, по тапу не открывается.
- Иерархия: `Программа → Неделя (1–4) → Занятия (1..N) → Упражнения`.
- **Все недели видны сразу** — на каждой написано число занятий и прогресс
  (неделя 1 = 4 занятия, неделя 2 = 5 и т.д., настраивается `weekPlan` в `db.js`).
- **Неделя N открывается через 7·(N−1) дней от регистрации:** записалась сегодня —
  доступна неделя 1, через 7 дней откроется неделя 2 и т.д. Заблокированная
  неделя показывает «Откроется через N дн.».
- Внутри открытой недели все занятия доступны сразу; первое незавершённое
  занятие помечено бейджем **«следующее»**.
- Контент загружаем мы (админка/загрузка программ — позже, сейчас заглушки в `db.js`).

### 2. Питание

- Список меню. Сейчас три заглушки:
  - «Похудение · ~1500 ккал»
  - «Поддержание · ~2000 ккал»
  - «Набор массы · ~2500 ккал»
- Внутри меню — приёмы пищи (завтрак / перекусы / обед / ужин) с блюдами,
  **ккал у каждого приёма** и строкой **КБЖУ** у всего меню.
- Дальше: раздел может стать платным (кнопка «Разблокировать» → оплата).

### 3. Мой профиль

- **Закреплённая шапка на всех страницах** (одной строкой): **пакет + остаток
  срока** слева (например «⭐ Старт · 30 дн.»), **розовое имя и возраст**
  (клик → профиль), **розовая плашка с текущим весом** (чёрный текст),
  **аватарка из Telegram** (`initDataUnsafe.user.photo_url`; если фото нет —
  круг с первой буквой имени; тоже клик → профиль).
- Пакеты: ⭐ Старт, 🥜 Уверенная, 👑 VIP. Пока заглушка: при онбординге
  выдаётся «Старт» на 30 дней; после оплаты (этап 2) пакет и срок будут
  приходить с сервера.
- На вкладке — **график изменения веса** (SVG-линия по всем записям, без
  библиотек) со стартовым весом и дельтой; у первой и последней точки —
  метки значений.
- Под графиком — кнопка **«Внести данные»**: открывает форму с выбором даты
  и полем веса. Одна запись на дату (повторная перезаписывает), записи
  хранятся по хронологии.
- В форме — **список последних записей с кнопкой удаления** (×): ошибочную
  точку можно стереть. Дата в будущем отклоняется.
- Кнопка **«Изменить имя/возраст»** — правка данных профиля после онбординга.

## Упражнение и трекинг

Карточка упражнения содержит:

- название;
- **план**: подходы × повторы × вес (например, 4 подхода × 8 × 50 кг);
- **видео техники** — как правильно выполнять (YouTube «по ссылке» или файл в Telegram);
- текст техники;
- поля для **факта** выполнения: по каждому подходу вес + повторы.

- Отметка «выполнено» на уровне упражнения; после сохранения автоматически
  раскрывается и подвозится к следующему упражнению. Поля факта можно
  оставить пустыми. У выполненного есть кнопка **«Снять отметку»**.
- Прогресс-бар на уровне занятия / недели / программы.
- История: пользователь видит последнюю запись и до 4 предыдущих
  (динамика прогресса по упражнению).

## Экраны

1. **Онбординг** — имя / возраст / вес.
2. **Таб «Программы»** — фильтры (пакеты, «доступное мне», группы, хэштеги) + список программ.
3. **Программа** — все 4 недели со статусами (текущая/готово/🔒 + «откроется через N дн.»).
4. **Неделя** — занятия 1..N со статусами (готово/частично).
5. **Занятие** — список упражнений-аккордеонов с планом и вводом факта.
6. **Таб «Питание»** — список меню → меню с приёмами пищи.
7. **Таб «Мой профиль»** — данные + редактирование веса + график.

## Технические детали (Telegram-интеграция)

- `setHeaderColor` / `setBackgroundColor` под цвет фона — мини-апп выглядит нативно.
- **Темы: тёмная и светлая.** В профиле переключатель «Авто / Тёмная /
  Светлая»; «Авто» следует за темой Telegram (`themeParams.bg_color`),
  ручной выбор сохраняется и имеет приоритет. Розовый акцент в обеих темах.
- `BackButton` Telegram — показывается на вложенных экранах, ведёт назад
  (работает и железная кнопка Android).
- `enableClosingConfirmation` + `disableVerticalSwipes` — случайный свайп
  не закроет апп посреди ввода.
- **Валидация `initData`** на сервере (HMAC-SHA256 по BOT_TOKEN) — подделать
  чужого пользователя нельзя; `auth_date` старше суток отклоняется;
  в деве без токена проверка отключена.
- localStorage-ключи привязаны к `tg_id` — два аккаунта на устройстве не
  делят профиль и логи. Пользовательский ввод экранируется при выводе (`esc`).
- **Истёкший пакет** = нет доступа: все программы показываются под замком.
- Имя, аватар и пр. выводятся через `esc()`; аватарка с фиксированными размерами.
- Тост «Сохранено» после записей (в браузере без хаптиков), кнопки сохранения
  защищены от двойного тапа, скролл восстанавливается при «назад», при фокусе
  инпут подвозится в центр экрана (клавиатура). Инпуты 16px — iOS не зумит.
- Тема следует за `themeChanged` на лету.
- Ошибка загрузки данных → экран «Не удалось загрузить» + кнопка «Повторить».
- График веса: ось X по реальным датам; подписи дат прорежены при 15+ точках.
- **Антикэш:** `build-static.js` инжектит `?v=<build>` в ссылки на ассеты —
  вебвью ТГ подхватывает новую версию сразу после деплоя.
- Программа, пройденная на 100%, помечена бейджем «🏁 пройдена».
- В серверном режиме `data.js` не подключается (нет 404 в консоли) — тег
  инжектится только при статической сборке.
- **e2e-тест:** `node app/test/smoke.mjs` — поднимает `docs/` на :8094 и
  прогоняет 41 проверку в отладочном Chrome (:9222).

## Модель данных (черновик)

```
profile (localStorage) — имя, возраст, since (дата регистрации),
                         weights[{дата, вес}], pack{ id, until }
accounts (accounts.json) — tg_id → { user_name, first_name, created, seen }
programs       — id, название, описание, уровень,
                 packs[пакеты доступа], group(группа),
                 weekPlan[занятий в каждой неделе]
groups         — id, название
weeks          — program_id, номер недели (1–4)
workouts       — week_id, номер занятия, название
exercises      — workout_id, название, порядок,
                 план: подходы, повторы, вес, техника, видео
menus          — id, название, описание, kbju,
                 meals[{приём, блюдо, ккал}]
logs           — user_id, exercise_id, дата,
                 факт: подходы[{вес, повторы}], выполнено,
                 hist[до 5 предыдущих записей]
```
