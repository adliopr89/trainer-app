# MVP — спецификация Mini App

> Функциональность первой версии. Дополняется по ходу обсуждения.

## Структура приложения

### Уровни сложности (3 плашки/таба снизу)

- **Новичок**
- **Опытный**
- **Профи**

Нижняя навигация Mini App — 3 таба, по одному на уровень.

### Программы и доступ по календарю

- Внутри каждого уровня — программа, разбитая на недели (контент грузим помесячно, по 4 недели).
- Иерархия: `Уровень → Программа → Неделя → Дни (Пн–Вс) → Упражнения`.
- **Пользователю видна только текущая неделя.** Остальные недели скрыты.
- **Дни открываются по календарю:** сегодня пятница → доступны тренировки Пн–Пт этой недели; завтра откроется Сб и т.д. Прошлые дни недели остаются открытыми (можно догнать), будущие — заблокированы с пометкой «откроется в <день>».
- В понедельник неделя обновляется — открывается новая неделя программы.
- Контент загружаем мы (админка/загрузка программ — позже, на MVP — заглушки/JSON).

### Упражнение

Карточка упражнения содержит:

- название;
- **план**: подходы × повторы × вес (например, 3 подхода × 50 кг);
- **видео техники** — как правильно выполнять (YouTube «по ссылке» или файл в Telegram);
- поля для факта выполнения (см. ниже).

## Трекинг достижений

Ключевая фича: пользователь отмечает **фактический** результат, который может отличаться от плана.

- План: `3 подхода × 50 кг` → пользователь вводит факт: `3 подхода × 45 кг`.
- Лог по каждому подходу: вес + повторения (гибче, чем одно число).
- Отметка «выполнено» на уровне упражнения; день считается закрытым, когда выполнены все упражнения.
- Прогресс-бар на уровне дня / недели / программы.
- История: пользователь видит свои прошлые записи по упражнению (динамика весов).

## Экраны (черновик)

1. **Табы уровней** — Новичок / Опытный / Профи.
2. **Список программ уровня** → карточка программы (4 недели).
3. **Неделя** — список дней со статусами (выполнен/частично/нет).
4. **Тренировка дня** — список упражнений с планом и чекбоксами.
5. **Упражнение** — видео техники + план + ввод факта (подходы, вес, повторы) + история.

## Модель данных (черновик)

```
users          — tg_id, имя, дата регистрации
levels         — новичок / опытный / профи
programs       — level_id, название, порядок
weeks          — program_id, номер недели (1–4)
workouts       — week_id, день, название
exercises      — workout_id, название, порядок,
                 план: подходы, повторы, вес
exercise_media — exercise_id, видео (url/file_id)
logs           — user_id, exercise_id, дата,
                 факт: подходы[{вес, повторы}], выполнено
```

## Что нужно для запуска (чеклист)

- [ ] **Бот в @BotFather** — токен + настройка кнопки меню на Mini App.
- [ ] **Сервер 24/7** — Render/Railway free tier или VPS (~200–400 ₽/мес).
- [ ] **HTTPS-домен** — обязательное требование Telegram для Mini App. Vercel/Netlify дают бесплатный HTTPS-поддомен; на VPS — домен + Let's Encrypt/Cloudflare.
- [ ] **БД** — SQLite на старте или Supabase free tier.
- [ ] **Видео** — YouTube «по ссылке» или Telegram file_id.
- [ ] **Для разработки** — туннель ngrok/localtunnel (HTTPS к localhost).
- [ ] **Контент от тренера** — программы по неделям (упражнения, подходы, веса) + отснятые видео техники.
- [ ] **Оплата (этап 2)** — Telegram Stars (без расчётного счёта) или Prodamus/YooKassa (нужен самозанятый/ИП).
