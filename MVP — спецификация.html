1Бот

На команду /start бот отвечает сообщением с двумя кнопками:

«Оплатить» — пока заглушка (ответ «скоро появится»). Дальше: Telegram Stars / Prodamus / YooKassa + выдача доступа.этап 2
«Открыть приложение» — открывает Mini App по адресу из WEBAPP_URL.

Бот здоровается по имени (ctx.from.first_name).

База аккаунтов — app/data/accounts.json (в gitignore): при /start и при входе в Mini App (POST /api/me) пишется tg_id → { user_name, first_name, created, seen }. Полноценная БД клиентов — этап 2.

2Онбординг (первый вход в Mini App)

При первом открытии приложение просит заполнить:

  • Имя — подставляется из initDataUnsafe.user.first_name, можно править
  • Возраст
  • Вес, кг

Ошибки показываются под каждым полем, невалидное поле подсвечивается розовым. После сохранения показывается основной интерфейс. Вес из онбординга — первая точка в истории веса.

3Структура приложения — нижние плашки

Таб 1 · Программы

  • Список программ. Сейчас две: «Крепкий орех» (силовая, Опытный, 🥜+👑) и «Хуяе как худею» (жиросжигание, Новичок, все пакеты).
  • Карточка программы: название, розовой строкой — уровень, пакеты, длительность в неделях, описание, группа, прогресс-бар выполнения.
  • Фильтры сверху: чипы пакетов (Все / ⭐ Старт / 🥜 Уверенная / 👑 VIP) + чекбокс «Доступное мне» (включён по умолчанию); чипы групп (Все / Формы / Похудение / Набор массы).
  • Программа не из пакета пользователя — серая с 🔒, по тапу не открывается.
  • Иерархия: Программа → Неделя (1–4) → Занятия (1..N) → Упражнения.
  • Все недели видны сразу — на каждой число занятий и прогресс (неделя 1 = 4 занятия, неделя 2 = 5 …, настраивается weekPlan в db.js).
  • Неделя N открывается через 7·(N−1) дней от регистрации: сегодня — неделя 1, через 7 дней — неделя 2 и т.д. Заблокированная показывает «Откроется через N дн.». Внутри открытой недели все занятия доступны сразу; первое незавершённое помечено бейджем «следующее».

Таб 2 · Питание

  • Список меню. Сейчас три заглушки: «Похудение · ~1500 ккал», «Поддержание · ~2000 ккал», «Набор массы · ~2500 ккал».
  • Внутри меню — приёмы пищи (завтрак / перекусы / обед / ужин) с блюдами, ккал у каждого приёма и строкой КБЖУ у всего меню.
  • Дальше: раздел может стать платным — кнопка «Разблокировать» → оплата.этап 2

Таб 3 · Мой профиль

  • Закреплённая шапка на всех страницах (одной строкой): пакет + остаток срока слева («⭐ Старт · 30 дн.» — нажатие ведёт в профиль), имя и возраст, розовая плашка с текущим весом (чёрный текст), аватарка из Telegram (initDataUnsafe.user.photo_url; если фото нет — круг с первой буквой имени).
  • Пакеты: ⭐ Старт, 🥜 Уверенная, 👑 VIP. Пока заглушка: при онбординге выдаётся «Старт» на 30 дней; после оплаты пакет и срок придут с сервера.этап 2
  • На вкладке — график изменения веса (SVG-линия по всем записям, без библиотек) со стартовым весом, дельтой и метками значений у первой и последней точек.
  • Под графиком — кнопка «Внести данные»: открывает форму с выбором даты и полем веса. Одна запись на дату (повторная перезаписывает), дата в будущем отклоняется. В форме — список последних записей с удалением (×).
  • Кнопка «Изменить имя/возраст» — правка данных профиля после онбординга.

4Упражнение и трекинг

Карточка упражнения: название; план (подходы × повторы × вес); видео техники (YouTube «по ссылке» или файл в Telegram); текст техники; поля факта — по каждому подходу вес + повторы.
  • Отметка «выполнено» на уровне упражнения; после сохранения раскрывается и подвозится к следующему. У выполненного — кнопка «Снять отметку».
  • Прогресс-бар на уровне занятия / недели / программы.
  • История: последняя запись + до 4 предыдущих видны в карточке.

ТТехнические детали (Telegram-интеграция)

  • setHeaderColor / setBackgroundColor под фон приложения.
  • Светлая тема: светлый themeParams.bg_color → светлая палитра (розовый акцент сохраняется).
  • BackButton Telegram на вложенных экранах + enableClosingConfirmation + disableVerticalSwipes.
  • Валидация initData на сервере (HMAC-SHA256 по BOT_TOKEN, auth_date не старше суток); в деве без токена отключена.
  • localStorage-ключи привязаны к tg_id; пользовательский ввод экранируется при выводе (esc()).
  • Истёкший пакет = нет доступа: все программы под замком.
  • Тост «Сохранено», антидвойной тап кнопок, восстановление скролла при «назад», инпуты 16px (iOS без зума), тема по themeChanged.
  • Ошибка загрузки → «Не удалось загрузить» + «Повторить». График веса: X по реальным датам, подписи прорежены при 15+ точках.
  • Антикэш: build-static.js инжектит ?v=<build> в ссылки на ассеты.
  • Программа на 100% помечена «🏁 пройдена». В серверном режиме data.js не подключается (тег инжектится при сборке).
  • e2e: node app/test/smoke.mjs — 41 проверка в отладочном Chrome (:9222).

5Экраны

  • Онбординг — имя / возраст / вес
  • Таб «Программы» — фильтры (пакеты, «доступное мне», группы) + список
  • Программа — все недели со статусами (текущая / готово / 🔒 + «откроется через N дн.»)
  • Неделя — занятия 1..N со статусами (готово / частично)
  • Занятие — упражнения-аккордеоны с планом и вводом факта
  • Таб «Питание» — список меню → меню с приёмами пищи
  • Таб «Мой профиль» — шапка с аватаркой + график веса + «Внести данные» (дата + вес)

6Модель данных (черновик)

profile (localStorage) — имя, возраст, since (дата регистрации),
                         weights[{дата, вес}], pack{ id, until }
accounts (accounts.json) — tg_id → { user_name, first_name, created, seen }
programs       — id, название, описание, уровень,
                 packs[пакеты доступа], group(группа),
                 weekPlan[занятий в каждой неделе]
groups         — id, название
weeks          — program_id, номер недели (1–4)
workouts       — week_id, номер занятия, название
exercises      — workout_id, название, порядок,
                 план: подходы, повторы, вес, техника, видео
menus          — id, название, описание, kbju,
                 meals[{приём, блюдо, ккал}]
logs           — user_id, exercise_id, дата,
                 факт: подходы[{вес, повторы}], выполнено,
                 hist[до 5 предыдущих записей]

7Что нужно для запуска

  • Бот в @BotFather — @pahs_trener_bot, токен в app/.env
  • Публикация — GitHub Pages (docs/ собирается build-static.js)
  • Привязка — setChatMenuButton открывает Mini App
  • Сервер 24/7 — когда включим оплату и БД клиентов (Render/Railway/VPS)
  • Оплата (этап 2) — Telegram Stars или Prodamus/YooKassa
  • БД клиентов (этап 2) — профили, доступы, оплаты (SQLite/Supabase)
  • Видео — YouTube «по ссылке» или Telegram file_id
  • Контент от тренера — реальные программы и меню + видео техники

Запуск для разработки:

node server/index.js          # бот + API + webapp (нужен .env)
node server/build-static.js   # статическая сборка → docs/
node app/test/smoke.mjs       # e2e: 41 проверка в отладочном Chrome
