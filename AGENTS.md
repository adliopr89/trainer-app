# Онлайн тренер — контекст проекта

> Этот файл — памятка для Devin. Читать в начале каждой сессии по этому проекту.

## Суть проекта

Друг пользователя — тренер в зале (офлайн). Хочет запустить онлайн-курсы для девушек 18–55 лет: видео-тренировки + питание. Старт с нуля: 0 подписчиков, есть только 4 действующие клиентки в зале (использовать как кейсы «до/после»).

Референс, который нравится владельцу: https://anastasiazolotaya.tilda.ws/tseh (Анастасия Золотая — фитнес-марафоны, лендинг на Tilda + своё мини-приложение в Telegram).

## Стратегия воронки (утверждено обсуждением)

```
Короткие видео (VK Clips / YouTube Shorts / Reels)
        → Telegram-канал + бот
        → Mini App с бесплатной программой тренировок (лид-магнит)
        → платный курс внутри того же Mini App
        → апселлы: питание, следующие потоки, рефералка
```

- Основной канал: **Telegram** (канал + чат + бот).
- Трафик: короткие видео 3–5 шт/неделю + офлайн-трафик зала (QR-код, сарафан) + локальные коллабы.
- Лид-магнит: **бесплатный Telegram Mini App** — трекер тренировок с одной бесплатной программой (например «Старт: 2 недели»). Подписка на канал = условие доступа.
- Монетизация: платный курс внутри Mini App, заблокированные разделы «Питание» и «Курс 8 недель» → кнопка «Разблокировать».
- Оплата: Telegram Payments / Stars или Prodamus/CloudPayments/YooKassa, доступ выдаёт бот.
- Первый поток: «бета» дёшево или бесплатно за отзыв (5–10 человек) — собрать кейсы.

## Что НЕ делать

- Не покупать GetCourse на старте — достаточно Mini App + бот.
- Не делать лендинг на Tilda до первого платного набора — хватит канала и бота.
- Mini App не генерирует трафик сам — это конверсия и удержание, трафик идёт из контента.

## Технические решения (статус)

- [x] Стек бота: **Node.js** — grammY + Express. Фронт MVP — ванильный JS (без сборки), React позже при необходимости.
- [x] Mini App: Telegram Web Apps API, стили под нативную тему ТГ (CSS-переменные tg-theme).
- [x] Бэкенд MVP: **статический режим** — фронт работает без сервера: данные зашиты в `docs/data.js`, логи весов в localStorage. Express+JSON (`app/server/`) оставлен как будущий API.
- [x] Публикация: **GitHub Pages** — `https://adliopr89.github.io/trainer-app/` (репо `adliopr89/trainer-app`, git-root = корень проекта `Онлайн тренер/`, публикуется корневая папка `docs/` с ветки main). Постоянный адрес, без заглушек, не зависит от ПК пользователя.
  - Workflow: правим `app/server/db.js` (данные) и `app/webapp/` (UI) → `node app/server/build-static.js` (собирает в корневой `docs/`) → `git add -A && git commit && git push` → Pages подхватывает за ~1 мин.
  - `webapp/app.js` имеет два режима: `window.APP_DATA` есть → localStorage-режим (GitHub Pages); нет → fetch к API (`server/index.js`, :3000).
  - Меню-ботонка `setChatMenuButton` уже указывает на Pages-адрес; `/start` в боте ходит через `WEBAPP_URL` в `.env`.
  - Не работает из сети РФ: Cloudflare tunnel (7844 blocked), Tailscale Funnel (edge IP рвутся ТСПУ), ngrok free (заглушка «Visit Site» не жмётся в вебвью ТГ). Туннели больше не нужны.
- [ ] Видео: YouTube «по ссылке» или Telegram-файлы (без CDN).

## Роадмап разработки

1. **Этап 1 — каркас лид-гена:** бот (проверка подписки, выдача доступа) + Mini App по спецификации: 3 уровня (новичок/опытный/профи) табами снизу, видна только **текущая неделя**, дни открываются по календарю (Пн–Вс, будущие дни заблокированы), текущая неделя считается от первого входа пользователя. Упражнения: видео техники + лог факта (подходы×вес×повторы). См. `MVP — спецификация.md`.

   **Статус:** каркас написан и работает (`app/`), сервер на :3000, туннель localhost.run. Ожидает BOT_TOKEN в `app/.env`.
2. **Этап 2 — монетизация:** платный курс, оплата, доступы, раздел питания.
3. **Этап 3 — удержание:** напоминания через бота, стрики, дневник питания, рефералка.

## Контент (для справки)

- Кейсы 4 клиенток — главный стартовый актив (фото до, замеры, видео-отзывы).
- Темы роликов: разборы техники «так/не так», рацион тренера, развенчание мифов, куски тренировок клиенток.
